# How to Network at an AI Conference: NeurIPS 2026 Social

Event website for the NeurIPS 2026 social **"How to Network at an AI Conference"**, a lighthearted, two-hour, structured session that helps attendees turn conference networking from an awkward ordeal into real connections.

**Live site:** https://gitlippe.github.io/neurips-2026-networking-social/

## What's on the page
- Event description and the research behind it
- The 2-hour agenda (intro, icebreakers & speed-networking, themed round tables, wrap-up & mingling)
- Organizers: Judah Goldfeder (Columbia University), Philippe Wyder (University of Washington), Karime Maamari (Distyl AI), Ravid Schwartz Ziv (New York University), Yoni Brander (Innodata), Chirag Sharma (Distyl AI)
- References
